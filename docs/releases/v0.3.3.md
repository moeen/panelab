# PaneLab v0.3.3

## Highlights

A maintenance release. The app works the same as 0.3.2; releases are now built as reviewed drafts and checked with the same signature, checksum, and bundle rules the in-app updater uses before they are published.

### Maintenance

- Tag builds create a draft release from reviewed notes, after checking the version, main CI for the tagged commit, and the signed update files ([#1](https://github.com/moeen/panelab/pull/1)).
- The in-app updater and the release check share one verification module, and the CLI, Lab status, and MCP server read their version from `package.json` ([#1](https://github.com/moeen/panelab/pull/1)).
- An opt-in smoke test launches the packaged app and checks frames from Chromium, WebKit, and Firefox ([#1](https://github.com/moeen/panelab/pull/1)).

None.

## Installation and updates

macOS 15+ on Apple Silicon. Download [PaneLab-0.3.3-arm64.zip](https://github.com/moeen/panelab/releases/download/v0.3.3/PaneLab-0.3.3-arm64.zip), unzip, and move PaneLab.app to /Applications.

The app is unsigned and unnotarized. For the first launch, clear quarantine with `xattr -dr com.apple.quarantine /Applications/PaneLab.app`. Existing installations on 0.3.0 or newer can update in the app; older versions need one manual update. Update downloads require PaneLab's Ed25519 signature and checksum verification.
